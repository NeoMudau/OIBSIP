# Java Task 3 – ATM Interface

## Overview
A console-based ATM simulation developed using Java and Object-Oriented Programming (OOP) principles.

## Features
- User authentication using User ID and PIN.
- Maximum of three incorrect login attempts.
- Main menu after successful authentication.
- Basic banking transactions.
- Input validation and transaction handling.

## Technologies
- Java
- Object-Oriented Programming (OOP)
- Java Console I/O

## Project Structure
Source code and related project files are contained in this folder.

## Running the Application
Compile and run the main Java class using a Java compiler or IDE.
